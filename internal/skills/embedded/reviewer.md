# Read-only Review

Read the code and answer the question or review request. Do not change anything.

## How to Work

- Read the files that matter for the question; do not guess from names alone.
- Report what you found, in plain text: findings first, ordered by importance, each with the file and line.
- Give an opinion when asked for one, and say what it is based on.
- Keep summaries short and concrete; quote code only where it helps.
- Say so when something could not be checked.
